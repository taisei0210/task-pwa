# task-pwa

「有効化日時」が来たタスクだけを表示する、個人用のタスク管理PWA。

## 考え方

タスク管理で一番のリスクは、数が増えてタスクが埋もれること。
そこで**期限は付けず**、代わりに **有効化日時（＝そのタスクに着手し始める日）** を設定し、
その日が来るまで一覧に出さない。目に入るのは常に「今やれるタスクだけ」になる。

- 表示条件：**未完了 かつ（有効化日時 ≤ 今日 または 未設定）**
- 完了したタスクは一覧から消え、データ側からも削除される（別途ログには残る）

## 使い方

1. 入力欄に打って Enter。末尾に日付を書くと自動で有効化日時になる
   （`銀行行く 明日` / `パスポート更新 8/24` / `本を返す +3` / `来週` / `明後日`）
2. ○をタップで完了。4秒だけ「取り消す」が出る
3. 圏外でも追加・完了でき、オンラインに戻ると自動で送信される

## 構成

- フロント：この静的ファイル一式（`index.html` に全部入り）
- バックエンド：Google スプレッドシート ＋ Apps Script のウェブアプリ

接続先のAPIのURLは**このコードには含めず**、初回起動時に入力して端末の localStorage にだけ保存する。
そのためこのリポジトリを公開しても、データにはアクセスできない。

## セットアップ

Apps Script 側のコードとデプロイ手順は、作者の手元（Obsidian Vault）で管理している。
このリポジトリは配信用の静的ファイルのみ。
